# 30-Day Interview Preparation Plan

**Time budget:** 50 minutes/day (about 25 focused hours).  
**Outcome:** a focused interview-readiness milestone, not mastery of every technology or a guaranteed offer.

| Days | Focus | Deliverable |
|---|---|---|
| 1–5 | Core Java, collections, coding, JVM | Java notes + tested coding solutions |
| 6–9 | Concurrency and Spring | Thread-safe examples + Spring request flow |
| 10–13 | SQL, PostgreSQL, JPA, security | Schema, query analysis and secured API design |
| 14–17 | Kafka, microservices, distributed systems | Reliable event flow, idempotency and outbox design |
| 18–21 | System design and resilience | HLD/LLD diagrams and failure handling |
| 22–24 | AWS, Azure, Docker, Kubernetes | Deployment architecture and service mapping |
| 25–27 | Flagship project | End-to-end order flow with tests and documentation |
| 28–30 | Mock interviews and applications | Interview review, profile and application assets |

## Daily format
- 15 minutes: concept.
- 20 minutes: coding / hands-on / architecture drawing.
- 10 minutes: production scenario.
- 5 minutes: recall and tracker update.

## Priority rule
Prioritise Java coding, concurrency, distributed systems, system design and explaining trade-offs. Cloud coverage should focus on architecture and a small, safe hands-on deployment rather than trying to learn every service.

## Company-oriented emphasis
- Cohesity / Rubrik: concurrency, distributed systems, storage concepts, reliability and coding.
- Nutanix: distributed architecture, fault tolerance and system design.
- Broadcom / VMware: Java internals, backend architecture, networking fundamentals, cloud and Kubernetes.

These are preparation emphases, not claims about any specific interview loop.
