# Java Architect – 30-Day Preparation

A practical preparation and portfolio repository for a senior Java full-stack engineer targeting Senior Engineer, Tech Lead, Staff Engineer and Architect opportunities.

## Goals
- Strengthen Java internals, coding, concurrency and JVM fundamentals.
- Practise Spring Boot, security, databases, Kafka and distributed systems.
- Design resilient systems and explain architecture trade-offs.
- Build an Enterprise Order & Inventory Platform as a demonstrable portfolio project.
- Maintain interview scenarios, revision notes and progress transparently.

## Repository map
- `00-roadmap/` – 30-day plan and progress tracker.
- `01-core-java/` – Java internals and language concepts.
- `02-coding-interviews/` – coding problems and solutions.
- `03-spring-security/` – Spring Boot and application security.
- `04-databases/` – SQL, PostgreSQL, indexing and JPA.
- `05-microservices-kafka/` – messaging and distributed systems.
- `06-system-design/` – HLD, LLD and trade-offs.
- `07-cloud-aws-azure/` – cloud architecture.
- `08-docker-kubernetes/` – containers and orchestration.
- `09-interview-scenarios/` – production scenarios and answers.
- `10-enterprise-order-platform/` – flagship project.
- `11-interview-revision/` – concise revision sheets.

## Daily study loop (50 minutes)
1. 15 min – learn and explain the concept.
2. 20 min – implement or draw the design.
3. 10 min – answer a production scenario aloud.
4. 5 min – revise and update the tracker.

If a session is interrupted, resume from the last unchecked item. Do not sacrifice sleep to recover a missed session.

## Working agreement
- All code should compile and be tested before being marked complete.
- Record assumptions, trade-offs and limitations.
- Never commit credentials, tokens, private customer data or employer-owned code.
- Do not invent performance metrics. Measure them if you want to publish them.
- Keep the project appropriately scoped: demonstrate sound boundaries rather than splitting everything into microservices just to list technologies.
